🗑️ Java Array Deletion — Visual Demo
An educational project that visually demonstrates how element deletion works in a Java array — showing the index-shifting process that happens when an element is removed.
What it includes:

DeletionNumber.java — Core Java logic for deleting an element from an array by shifting elements left
deletion_number.html — Interactive browser-based visualization of the deletion process

Great for:

DSA beginners learning how arrays work under the hood
Understanding why array deletion is an O(n) operation
Visualizing index shifting step by step
